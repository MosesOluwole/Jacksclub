# Jacksclub Developer Test

## Clone the repo

Git Clone the repo

```bash
$ git clone https://github.com/MosesOluwole/Jacksclub.git
```

Then...

```bash
$ cd Jacksclub
```

Task 1: Retrieve Current Balance Function can be found in the below

```bash
$ src/balance
```

Task 2: Transact Function can be found in the below

```bash
$ src/transaction
```

## Install npm packages and dependencies

```bash
$ npm install
```

## Run test

```bash
$ npm test
```
